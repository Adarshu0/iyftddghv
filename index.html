Designing with intention. Coding without shortcuts.

I'm Adarsh, a digital designer and frontend developer with an obsessive focus on craft, typography, and micro-interactions. Over the past 5+ years, I've worked across product design, design systems, and creative web engineering.

I believe modern digital products shouldn't feel like generic templates. Great work requires generous negative space, intentional typography, frictionless user flows, and code architectures that run at a smooth 60 frames per second.

When I'm not pushing pixels in Figma or writing clean vanilla JavaScript, you'll find me experimenting with generative canvas graphics, curating ambient synth tracks, or testing web accessibility standards.
